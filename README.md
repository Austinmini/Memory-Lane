# Memory Lane

**Memory Lane** is a local-first mobile companion designed to support individuals living with dementia (Alzheimer's / cognitive impairment) and provide peace of mind to their family caregivers.

## Key Pillars
1. **Loved Ones & Memory Carousel**: Calming, high-contrast visual photo album of family, friends, pets, and milestone memories with names, relationships, and soothing English text-to-speech readouts.
2. **Voice-Guided Daily Reminders**: Routine assistant announcing essential daily tasks (medication, hydration, meals, family calls) using soothing voice prompts and local notifications.
3. **100% On-Device Privacy**: All photos, personal stories, and schedules reside strictly on the user's device (offline-first SQLite & internal sandbox storage). Zero cloud transmission, zero tracking.

## Tech Stack
- **Framework**: React Native with Expo (TypeScript)
- **Database**: expo-sqlite
- **Storage**: expo-file-system
- **Speech**: expo-speech
- **Notifications**: expo-notifications
